نام سرویس

سرویس Create Financial Institution Transfer Message

شرح سرویس و قوانین کسب و کار

این سرویس مسئول دریافت اطلاعات کسب‌وکاری مورد نیاز برای انتقال وجه بین
مؤسسات مالی و ایجاد یک پیام مالی استاندارد جهت ارسال به شبکه پیام‌رسان
انتخاب‌شده است.

سرویس باید بدون وابستگی مصرف‌کننده به ساختار فنی پیام، اطلاعات دریافتی را
دریافت کرده، اعتبارسنجی کند و بر اساس Message Definition فعال، پیام
خروجی مناسب را ایجاد نماید.

سرویس دریافت درخواست ساخت پیام 200 به‌منظور ایجاد یک پیام انتقال وجه بین
مؤسسات مالی طراحی شده است. این سرویس اطلاعات کسب‌وکاری موردنیاز برای
انتقال وجه را از سامانه‌های متقاضی دریافت کرده و بدون وابسته کردن آن‌ها به
ساختار پیام‌های استاندارد، درخواست ایجاد پیام را پردازش می‌کند.

پس از دریافت درخواست، Platform اعتبارسنجی‌های فنی لازم را بر روی اطلاعات
ورودی انجام داده، Message Definition مناسب را بر اساس نوع پیام، شبکه
ارتباطی و تنظیمات فعال انتخاب می‌کند و سپس پیام استاندارد متناظر را ایجاد
می‌نماید. پیام ایجادشده به‌صورت یک Message Instance در سامانه ثبت شده و در
وضعیت Draft قرار می‌گیرد تا در صورت نیاز قبل از ارسال ویرایش، تکمیل یا
مجدداً اعتبارسنجی شود.

مسئولیت این سرویس صرفاً مدیریت فرآیند ایجاد پیام، اعمال قوانین فنی، تولید
ساختار استاندارد و مدیریت وضعیت پیام است و هیچ‌گونه اعتبارسنجی یا
تصمیم‌گیری مرتبط با فرآیندهای کسب‌وکاری مانند کنترل مجوز انتقال، اعتبار
حساب، موجودی، یا سایر قوانین تجاری را انجام نمی‌دهد. این مسئولیت‌ها بر
عهده سامانه‌های کسب‌وکار استفاده‌کننده از سرویس است.

این سرویس به گونه‌ای طراحی شده است که مستقل از استاندارد پیام و شبکه
پیام‌رسان بوده و بتواند از طریق Message Definition مناسب، برای یک درخواست
کسب‌وکاری، پیام متناظر را در قالب‌های مختلف و بر بستر شبکه‌های متفاوت تولید
کند؛ بدون آنکه قرارداد سرویس یا نحوه تعامل سامانه‌های کسب‌وکار تغییر کند.
